# Visualization

The `legend-pygeom-l1000` package provides powerful visualization capabilities
through VTK (Visualization Toolkit), allowing you to inspect and explore the
geometry interactively. Refer to
[GDML-Viewer](https://legend-pygeom-tools.readthedocs.io/en/stable/vis.html#gdml-viewer)
for more details on the usage and features.

## Basic Visualization

### Opening the Viewer

The simplest way to visualize a geometry is:

```console
legend-pygeom-l1000 --visualize
```

This generates the geometry using default settings and immediately opens an
interactive 3D viewer window.

## Reproducing the documentation renderings

The images on the {doc}`description` page are generated by
`docs/generate_docs_images.py`, which builds each view, hides or re-colours the
parts that are not its subject, and exports a PNG headlessly:

```console
python docs/generate_docs_images.py                 # all views
python docs/generate_docs_images.py string          # just one
python docs/generate_docs_images.py --fast          # coarse meshes, for iterating
```

or `make -C docs images`. The generated images are committed, so regenerating
them and looking at the diff is a convenient check that a geometry change did
only what was intended.
